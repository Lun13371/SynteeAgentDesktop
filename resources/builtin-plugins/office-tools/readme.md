# Office Tools — офисные документы

Встроенный плагин SynteeHelper: полный цикл работы с Word-документами (Excel — фаза 2).

## Тулы (для AI)

| Тул | Что делает |
|---|---|
| `word_create` | Создание .docx из JSON-спеки: стили, списки, таблицы (merged/borders/fills), картинки, TOC, колонтитулы, настройка страницы |
| `word_spec_docs` | Полный справочник формата спеки (вызывай перед сложными документами) |
| `word_read` | Чтение .docx: `structure` / `text` / `full` / `stats` |
| `word_edit` | Гранулярные правки существующих .docx (массив операций) |
| `word_append` | Дописать блоки в конец документа |
| `office_open` | Открыть файл в реальном Word (COM) |
| `word_export_pdf` | Экспорт .docx → PDF (COM) |

## Панель

Правая панель «Office»: быстрые действия (новый документ/таблица/из шаблона), недавние файлы, настройки (папка сохранения, превью), живое превью текущего документа.

## Команда

`/office` — открыть панель.

## Рендеры в чате

- Карточка файла (после word_create) — имя, статистика, кнопки «Открыть» / «Показать в папке» / «PDF»
- Превью Excel-таблиц (фаза 2)

## Технологии

- Генерация: npm `docx` (ставится автоматически в папку плагина)
- Чтение: npm `mammoth`
- COM-автоматизация Word/Excel: PowerShell-скрипты (`process:exec`)
- Файлы по умолчанию: `Documents\Office Tools` (настраивается в панели)
