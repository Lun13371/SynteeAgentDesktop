Hello Page 🎉

Это полноэкранная страница плагина (registerPanel с slot: 'page').
Плагины могут быть целыми «приложениями внутри приложения» — kanban, трекеры, дашборды.

Как это работает:
registerPanel({ id: 'hwpage', slot: 'page', entry: 'ui/page.html' }) → вкладка в навигации приложения → iframe syntee-plugin://hello-world/ui/page.html.
