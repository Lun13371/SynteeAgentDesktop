# Plugin Dev — студия разработки плагинов

Встроенный плагин SynteeHelper: всё необходимое для создания собственных плагинов.

## Тулы (для AI)

| Тул | Что делает |
|---|---|
| `plugin_docs` | Полная документация plugin API. Без аргументов — оглавление, с `section` — конкретная секция |
| `create_plugin` | Скаффолдинг нового плагина: plugin.json + dist/index.js (шаблон) + readme.md + ui/panel.html |
| `list_plugins` | Список установленных плагинов с манифестами |
| `read_plugin` | Исходники плагина (манифест + entry или конкретный файл) |
| `validate_plugin` | Проверка плагина: манифест, права, entry, readme |
| `delete_plugin` | Удаление плагина (кроме встроенных) |

## Команда

`/plugin_dev` — открыть студию (модальная панель).

## Панель

Правая панель «Plugin Dev»: браузер документации (13 секций), мастер создания плагинов и список установленных.

## Для AI: как создать плагин

1. Прочитай доки: `plugin_docs(section="index")` → нужные секции (`tools`, `permissions`, …).
2. Вызови `create_plugin` с полной спецификацией (id, права, тулы, команды, withUi).
3. Плагин появится в списке — пользователь включит его (consent-диалог прав).
4. Правь код — hot-reload перезапускает плагин автоматически.
