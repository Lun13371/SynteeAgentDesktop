## Новые возможности

### Информер активности ИИ (ActivityManager)
Новый компактный виджет в overlay-окне, показывающий что делает агент (думает / вызывает тул / прогресс долгих тулов) пока главное окно неактивно или свёрнуто. По умолчанию выключен — включается в Settings → Уведомления.

- **ActivityManager (main)** — singleton, форвардит события из chat.ipc.ts:
  - `activity:run:status` — старт/конец работы агента
  - `activity:step` — шаг тулов (tool_call / tool_result / thinking)
  - `activity:tool_progress` — прогресс долгих тулов
- **shouldShow()** — проверяет enabled-флаг + окно неактивно/свёрнуто/скрыто
- **activeChats tracking** — minimize/blur → показать виджет; restore/focus → скрыть
- **Auto-hide** через 1.5 сек после done/error/cancelled
- **ensureVisible()** — показывает overlay если пользователь свернул окно после старта
- **Кэш enabled-флага** — обновляется при изменении настроек

### ActivityWidget (renderer)
Компактный glass-виджет с CSS backdrop-filter (без desktopCapturer — без DXGI лагов):
- Логотип Syntee + фаза ("Думает...", "read_file")
- Счётчик тулов
- Мини-строка с последними 3 тулами (✓ / ✗ / spinner)
- Spring-анимация появления/исчезновения
- AnimatePresence для exit-анимации
- onMouseEnter/Leave → setIgnoreMouseEvents toggle

### Client identity headers
APP_VERSION теперь инжектируется через Vite define из package.json (fallback `'0.1.0'` для non-Vite окружений). Во все исходящие API-запросы добавляются заголовки идентификации клиента:
- `User-Agent: syntee-agent/{version}`
- `X-Client-Name: syntee-agent`
- `X-Client-Version: {version}`

Провайдеры и прокси (включая Syntee-Gateway) могут идентифицировать источник запросов. Заголовки применяются в AIClient (chat completions), image.ipc (image generation) и gatewayClient.

## Исправления

- **Лаг курсора overlay** — cursor polling 16ms → 100ms (в 6× меньше `setIgnoreMouseEvents` toggling, DWM не лагает). Bounds update: `requestAnimationFrame` loop → `setInterval` 200ms (раньше 60 IPC/сек). `stopTracking` теперь вызывает `setIgnoreMouseEvents(true)` без `forward:true` — forward на скрытом окне лагает DWM. `show()`: `forward:true` включается только здесь (видимое окно — не лагает). Hide timer: 500ms → 200ms (короткая exit-анимация).
- **Обфускатор ломает dynamic imports** — Vite code splitting использует `import()` со статическими путями к чанкам (`./SettingsPage-Dq6IdtYq.js`). Если stringArray заменит эти пути вызовом функции-декодера, import() сломается → "Failed to fetch dynamically imported module" в release-сборке. `reservedStrings` сохраняет пути к `.js`/`.css` и относительные пути (`./`) в исходном виде.
