## Новые возможности

### Редактирование файлов: переход на str_replace
`edit_file` переработан — вместо сложного формата `apply_patch` с SEARCH/REPLACE блоками теперь используется простая замена `old_str` → `new_str`, как в Claude Code. Один режим, одна логика, меньше ошибок модели. Убраны режимы `insert` и `overwrite`.

### Роли суб-агентов
5 специализированных ролей для `spawn_agent`:
- **researcher** — только чтение (read-only)
- **deep-researcher** — чтение + веб-поиск/HTTP-запросы
- **editor** — чтение + редактирование файлов (без выполнения команд)
- **implementer** — полный доступ (по умолчанию)
- **reviewer** — только чтение для code review

Каждая роль ограничивает набор доступных тулов и добавляет свой system-prompt. В UI роли отображаются цветными бейджами.

### Overlay-уведомления
Новая система уведомлений поверх всех окон — прозрачный fullscreen overlay с click-through, droplet-карточки с блюром фона, spring-анимации:
- Уведомления о ответах AI, завершении агентов, запросах разрешений
- Per-type настройка (показывать всегда / когда неактивно / когда свёрнуто)
- Дебаунс спама, авто-закрытие при фокусе окна, стек до 5 уведомлений
- Pause-on-hover, action-кнопки

### Превью вложений (AttachmentPreviewModal)
Лайтбокс-модалка для просмотра вложений в полноэкранном режиме:
- Картинки: zoom колесом мыши (0.2x–5x), pan drag'ом, double-click reset
- Текстовые файлы: подсветка синтаксиса
- Бинарные файлы: иконка + "Открыть в системе"
- Esc / click outside / кнопка × для закрытия

### Кастомные шрифты
Импорт локальных шрифтов (.woff2/.ttf/.otf) с выбором UI и mono шрифтов. 6 новых встроенных шрифтов: Manrope, Onest, Sora, SpaceGrotesk, Unbounded, FiraCode (с кириллицей).

### Поиск звуков в интернете
Поиск звуков прямо из настроек через Internet Archive — бесплатно, без API-ключа. Debounce-поиск, пагинация, превью с эквалайзер-анимацией, фильтр коротких звуков, сохранение как кастомный звук.

### Граф знаний проекта (get_graph tool)
Новый тул `get_graph` — запрос графа знаний проекта (файлы, решения, концепты, связи). Визуализация графа памяти в отдельной вкладке настроек.

### TF-IDF поиск по памяти
Memory search перешёл на TF-IDF cosine similarity вместо LIKE pre-filter — находит семантически релевантные записи без точного совпадения подстроки.

### Vision passthrough
Если основная модель поддерживает vision, изображения передаются напрямую как multipart content (вместо описания vision-моделью). Улучшенное качество распознавания (detail: high, max_tokens 4096).

### Live ChangesBadge
Бейдж изменений показывается в реальном времени во время выполнения запроса, с shimmer-анимацией и slot-machine эффектом (RollingNumber) для счётчиков +N/-M.

### Undo checkpoint файлов
Восстановление всех файлов или отдельного файла из checkpoint'а указанного turn'а. Redo-баннер для отката.

### Поиск файлов в FileExplorer
Рекурсивный поиск файлов по имени/path (игнорирует node_modules/.git), с показом полного пути в результатах.

### GitPanel: автор + дата + body
Автор коммита, дата и полное сообщение (body) в списке лога и хедере диффа.

### Единая система motion-пресетов
Библиотека spring-пресетов framer-motion для консистентных тактильных анимаций. Page transitions с blur+scale эффектом. `motion.button` по всему проекту (46 файлов).

## Исправления

- **edit_file salvage** — если JSON не парсится, путь и old_str/new_str извлекаются по регексу; неправильная правка не применится (SEARCH не совпадёт → retry)
- **Loop-guard сброс** — счётчик loop-guard обнуляется при успешном выполнении тулзы; fingerprint теперь truncation head+tail (раньше edit_file блокировался на всей сессии)
- **Schema-aware валидация** — type coercion (string→number и т.д.), enum fuzzy-fix через Levenshtein, заполнение defaults, понятные сообщения об ошибках для модели
- **JSON repair** — 2 новых прохода: незакрытые скобки (до 4 шт.) и незакавыченные Windows-пути. Добавлена библиотека `jsonrepair` как fallback
- **Soft warning вместо hard block** — 1-2 parse failures дают soft warning, hard block только на 3+. Недеструктивные тулы (edit_file, save_memory, ask_user) не блокируются вообще
- **Vision stream timeout** — AbortController с таймаутом 60с на зависший vision-стрим
- **Прерывание обработки вложений** — `chat:stop` во время подготовки файлов теперь работает (AbortController + общий таймаут 120с)
- **Очередь после компакции** — повторный /compact даёт осмысленную ошибку; накопленные запросы запускаются автоматически после сжатия
- **git через execFile** — `exec` гнал команду через cmd.exe, который раскрывал `%H%`, `%an%` как env vars; `execFile` передаёт аргументы напрямую
- **Agent output при success=false** — тулы вроде `get_diagnostics` возвращают осмысленный output даже при success=false (раньше AI видел "Error: undefined")
- **ThinkingBlock gradient** — заменены theme-dependent переменные на стабильные `--text-primary`/`--text-secondary`
- **Overlay hide** — окно уведомлений скрывается после exit-анимаций (не перехватывает фокус)
- **Whisper cache** — `@huggingface/transformers` v4 не читает `TRANSFORMERS_CACHE` из env; явно выставляем `cacheDir`
- **AIClient onError** — callback при исчерпании всех 429-retries (не оставляем Promise висеть)
- **Terminal theme sync** — тема терминала читается из CSS-переменных вместо хардкода
- **Persist maximized** — maximized-флаг сохраняется отдельно, не перезаписывает windowBounds

## Производительность

- **Lazy windows** — Overlay/Voice/Spotlight/TrayMenu окна создаются лениво при первом show() (экономит ~4 renderer-процесса и сотни МБ RAM)
- **Dynamic imports** — Mermaid, vis-network, Overlay/Voice/Spotlight/LoginScreen грузятся по необходимости (экономия ~80-120MB RAM)
- **AnimatedBackground** — 8fps вместо 60fps + idle pause через 30с бездействия (0% CPU в idle)
- **Autoscroll** — rAF-loop работает только во время стрима; останавливается когда контент не растёт (минус 10-25% CPU)
- **SQLite PRAGMAs** — cache_size 64MB, mmap 256MB, synchronous NORMAL, temp_store MEMORY
- **LRU-кэши** — tiktoken estimateTokens (500), MessageBubble parse cache (200/150), agentCardCache (100)
- **Idle throttling** — polling не тикает когда окно скрыто (gateway models, theme scheduler, extensions detector, billing)
- **Overscan 10→5** — вдвое меньше ResizeObservers и активных MessageBubble listeners
- **Memory cleanup** — pruneStaleChatState, periodic orphaned buffer cleanup, cleanupTerminated agents
