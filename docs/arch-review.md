# Проверка Arch Linux x86_64

Проверено 17 ноября 2026 года. Основа — ветка `dev`, commit `4b6304d9d580ffb820ae6f604d94ebba8e4cfe2f`. Пакет `syntee-helper 1.1.4-2` собран и установлен через pacman в обновлённом Arch Linux под WSL2. Использованы Electron 44.5.0, Node 24.22.3 и Rust 1.100.0.

## Исправленные проблемы

- На чистой БД очистка вложений выполнялась до создания колонки `attachments`. Перенос очистки после миграции проверен на новой и существующей БД, включая сохранение единственной копии вложения.
- Windows-зависимые звук, автозапуск, загрузка llama.cpp, импорт браузеров, трей и обновление адаптированы для Linux. Звук использует PulseAudio API, включая совместимый `pipewire-pulse`. Обновление установленного пакета выполняется через pacman.
- Терминал различает Bash/Zsh, обнаруживает Fish/Nushell, использует доступную Linux-локаль `C.UTF-8`. Промпты передают фактическую ОС. Анализ проекта передаёт пути в Git как аргументы, поиск сохраняет сообщения об ошибках ripgrep.
- Monaco загружается при открытии файла или diff. Исправлена утечка моделей diff-редактора. Проверены пять циклов открытия и закрытия, редактирование файла и передача состояния `dirty`, после закрытия моделей не остаётся.
- Локальная LLM запускается при запросе или явной настройке. Отключение отменяет подготовку запуска, проверки GPU, health-запросы и перезапуски. Изменения параметров объединяются в один перезапуск. Загрузка GGUF одной модели выполняется одним потоком с backpressure. Повреждённый кэш llama.cpp восстанавливается.
- Пустой профиль пропускает подготовку E5. Появление данных возобновляет фоновую индексацию. Существующие embeddings сохраняют цикл очистки удалённых источников.
- FFT пропускается при цифровой тишине, скрытом и свёрнутом окне. Сохранены затухание и восстановление после показа. Устранена гонка подписок при переключении устройств во время асинхронного запуска захвата.

## Измерения

Сравнивались защищённые production-сборки с одинаковыми настройками, пустым гостевым чатом и включённым анимированным фоном. Базовая сборка содержит только исправление миграции, необходимое для первого запуска. Её модели были уже скачаны. Обе сборки запускались обычным пользователем в Xvfb/X11 под Arch/WSL2. PSS суммировался по дереву процессов приложения через `/proc/*/smaps_rollup`, тестовые Xvfb и Playwright в сумму не включены.

| Показатель | Базовая сборка | После изменений |
| --- | --- | --- |
| Суммарный PSS пустого чата | 2481,2 МиБ | 689,2–697,1 МиБ |
| JS heap главного renderer | 24,8 МиБ | 14,7–14,8 МиБ |
| Начальный renderer JS-бандл | около 14,54 МБ | около 5,64 МБ |
| PSS Rust-sidecar в пустом профиле | 426,1 МиБ | 6,8–7,8 МиБ |

Уменьшение PSS составляет около 72%. Основную экономию дают отложенные LLM/E5 и Monaco. После запуска локального инференса или индексации память потребуется для весов и рабочих буферов моделей. Эти значения описывают пустой чат, расход на больших проектах и длинных диалогах требует отдельного измерения.

Изолированный тест обработки 10 000 PCM-чанков тишины сократился с 669,5 до 133,9 мс при видимом окне и с 641,3 до 18,5 мс при скрытом. Этот тест измеряет CPU-время аудиообработки. Проверка заполнения и очистки поля ввода через Playwright заняла 24–36 мс в двух сборках, единичные замеры не устанавливают сравнительную скорость интерфейса.

## Проверки

- Пакет установлен через pacman. Проверены ELF x86_64, Linux ONNX, SQLite, node-pty, ripgrep, Rust-sidecar, права `chrome-sandbox`, desktop-файл и обработчик `synteehelper://`.
- 57 тестов Rust прошли.
- 20 регрессий миграций, Linux-платформы, аудио, E5-планировщика и освобождения diff-моделей прошли.
- 36 из 36 интеграционных проверок встроенного браузера прошли с временным локальным HTTP-сервером.
- Smoke-проверки импорта SQLite/WAL, запуска Chrome/Chromium, XDG-автозапуска через GIO, загрузки и жизненного цикла локальных моделей прошли.
- У установленного пакета проверены первый запуск, гостевой чат, ввод, открытие настроек, реальная Bash-команда через PTY, старт/остановка PulseAudio-захвата и статус Whisper. Явный запуск скачанной LLM 1.2B на CPU прошёл, после выхода из приложения её процесс завершился.
- Общий набор `tests/*.test.cjs tests/*.test.mjs` дал 159 успешных, 13 неуспешных и 8 пропущенных тестов. Те же 13 ошибок воспроизведены на исходном `dev`. Они относятся к устаревшим ожиданиям и заглушкам CodeMode, GoalRuntime и task-summary, полного зелёного набора у ветки нет.
- Полный TypeScript check остаётся неуспешным на существующих ошибках ветки. Сравнение с исходным `dev` показало 0 новых диагностик для main и renderer. Для изменённых TypeScript-файлов ESLint также показал 0 новых ошибок.
- `npm audit --omit=dev` сообщил о 19 предупреждениях в зафиксированных зависимостях, включая 7 high и 1 critical. Critical относится к транзитивному DOMPurify и режимам обработки DOM/shadow root с `SAFE_FOR_TEMPLATES`. Эксплуатация в приложении этой проверкой не установлена. Исходные версии библиотек сохранены, отдельная проверка обновлений зависимостей остаётся открытой. [Advisory DOMPurify](https://github.com/advisories/GHSA-cg2g-xh64-v4q7)

## Проверки на пользовательской системе

Работа видеодрайвера/Vulkan, системного keyring, микрофона, входа в gateway и конкретного Wayland compositor требует соответствующей среды и учётных данных. Native Wayland ограничивает позиционирование и верхний слой overlay-окон. Для XWayland доступен запуск `syntee-helper --ozone-platform=x11`.

Проверки подтверждают перечисленные сценарии. Гарантия отсутствия задержек на любых проектах и конфигурациях по этим измерениям не устанавливается.
