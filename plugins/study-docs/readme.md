# Study Docs

Помощник для учёбы: генерация и чтение Word/Excel — курсовые, рефераты, отчёты, лабы.
Оформление по ГОСТ 7.32 или своё, экспорт в PDF через установленный MS Word.

## Возможности

### Word — тулы (для AI)

| Тул | Что делает |
|---|---|
| `docx_read` | Прочитать .docx → markdown (заголовки, списки, таблицы, **жирный**/*курсив*). Шапка-статистика: слова, заголовки, ~страниц. `outline: true` — только структура (навигация по большим документам) |
| `docx_create` | Создать документ одним вызовом |
| `docx_start` → `docx_add` → `docx_finish` | **Сессия черновика для длинных работ (50+ страниц)**: старт (титульник+TOC) → главы по 3–8 секций за вызов → сборка. Ничего не перечитывается, титульник/TOC/формат не теряются |
| `docx_edit` | Дополнить (append) или пересобрать (replace) готовый файл, авто-бэкап `.bak.docx` |
| `docx_to_pdf` | Конвертация в PDF через MS Word (COM) + системное уведомление |

### Excel — тулы

| Тул | Что делает |
|---|---|
| `xlsx_read` | Листы, значения, формулы (`=SUM(A1:A2) → 42`) |
| `xlsx_create` | Книга с листами: данные, формулы, стили ячеек, объединения, закрепление шапки, автофильтр |
| `xlsx_edit` | Дозапись строк/листа в существующую книгу |

### Секции документа (docx_create / docx_add / docx_edit)

`titlePage` (титульник), `toc` (обновляемое содержание), `heading` (1–3 уровня),
`paragraph` (выравнивание), `list` (вложенные, `{text, level}`), `table` (шапка+заливка),
`code` (моно-блок с заливкой), `quote` (цитата), `formula` (по центру, номер `(1)`),
`image` (из файла, автонумерация «Рисунок N — …», авто-масштаб), `references` (нумерованный список источников), `pageBreak`.

**Инлайн-разметка в любом тексте:** `**жирный**`, `*курсив*`, `` `моно` `` — переживает
round-trip через docx_read/docx_edit (mammoth `<strong>`/`<em>` → маркеры).

**Колонтитул:** параметр `headerText` — бегущий заголовок на каждой странице.

### Ячейки Excel

Примитивы, строки с `=` (формулы) или объекты:
`{value|formula, bold, italic, align, format (numFmt, напр. '0.00'), fill ('#RRGGBB'), color, wrap}`.
Опции листа: `merges: ['A1:C1']`, `freeze: true|'B3'`, `autoFilter: true`.

### Команды

`/kursovaya <тема>`, `/referat <тема>`, `/otchet <тема>`, `/docx`, `/xlsx` (справка).

### Панель (правая, «Study Docs»)

- Сегмент-контрол типа документа + тема → промпт в чат
- **Баннер активного черновика** (файл + число секций, live через `ui.emit('draft')`)
- Отправка существующего .docx/.xlsx в чат на анализ
- Настройка оформления: ГОСТ или свой формат с живым превью
- «Мои файлы»: журнал до 50 файлов с датами, проводник, →PDF
- Бейдж на табе панели — число созданных файлов

### Интеграции в UI

Кнопка «Документ» над полем ввода → модалка · Spotlight-поиск по файлам ·
автокомплит `@doc` (вставить путь) · уведомление «PDF готов» · звук на создание.

## Формат ГОСТ 7.32 (пресет по умолчанию)

Times New Roman 14pt, полуторный интервал, поля 30/15/20/20 мм,
абзацный отступ 1.25 см, нумерация страниц снизу по центру (титульник без номера),
заголовки H1 — полужирные по центру с новой страницы, обновляемое содержание.

## Настройки (config)

- `defaultSaveDir` — папка для голых имён файлов (по умолчанию — Рабочий стол)
- `defaultFormat` — gost / custom

## Архитектура

```
dist/
├── index.js      — только wiring (activate → модули, deactivate → state.cleanup)
├── state.js      — state.api, форматы, журнал файлов, черновик, resolveSavePath, toPdf
├── tools.js      — тонкие тулы: валидация + вызов lib + бейдж-ответ
├── commands.js   — слэш-команды
├── ui.js         — панель + RPC + search/autocomplete/input-action
└── lib/
    ├── docx.js   — сборка/чтение Word (rich-text, картинки, формулы)
    └── xlsx.js   — чтение/запись/дозапись Excel (стили, merges, freeze)
```

`dist/vendor.js` — самодостаточный бандл (docx + mammoth + exceljs). Пересборка:

```bash
npm install
npx esbuild vendor-entry.js --bundle --platform=node --format=cjs --outfile=dist/vendor.js
```

`node_modules` в папке плагина не нужен (и вреден для вотчера) — после сборки удалить.

## Тесты

```bash
node tests/smoke.js        # без PDF (44 проверки)
node tests/smoke.js --pdf  # + конвертация через Word COM
```

## Права

`fs:read`, `fs:write:any` (запись документов пользователя), `ui` (панель, пикеры, вклады),
`process:exec` (PowerShell: PDF через Word, проводник), `notifications` (PDF готов),
`chat` (кнопки панели отправляют промпт в чат).
